# এক কমান্ডেই কাজ — AI-কে যা বলবেন

নিচের বাক্সগুলোতে শুধু আপনার নিজের কথাটা বসান। AI প্রথমে `docs/AI-GUIDE.md` পড়ে নেবে,
তারপর ঠিক ফাইলটা বদলে `build/build.py` চালাবে।

## ১. একটি পেজের চেহারা বদলাতে
```
docs/AI-GUIDE.md পড়ে #/panjika পেজের শিরোনাম-কার্ডটা আরও সরু ও সোনালি বর্ডারের করুন।
শুধু js/views/panjika.js ও css/reference.css বদলাবেন, তারপর build/build.py চালাবেন।
```

## ২. নতুন পেজ যোগ করতে
```
docs/AI-GUIDE.md-এর ৩ নং অংশ মেনে "ম Tulsi মালা" নামে নতুন পেজ যোগ করুন:
js/views/mala.js, build/manifest.json, js/core/75-router.js (#/mala)।
ডার্ক ও লাইট দুটোতেই দেখতে হবে।
```

## ৩. নতুন দেবতা / পূজা
```
js/puja-darpana.js-এ "চন্দ্র" দেবতার ১৮ ধাপের পূজা যোগ করুন (ধাপ আগে, মন্ত্র পরে)।
ছবি icons/deva/candra.png ও icons/deva/card/candra.png — ব্যাকগ্রাউন্ড ছাড়া,
অন্য দেবতাদের মতো একই মাপ (338×420, স্বচ্ছ PNG)।
```

## ৪. গান / ভিডিও / বই যোগ করতে (কোড ছাড়া)
```
অ্যাপে #/storage খুলে "＋ ফাইল যোগ করুন" দিয়ে ফাইল দিন;
গানের কার্ডে "সংগীত করুন" চাপলেই সেটি ব্যাকগ্রাউন্ডে বাজবে।
```

## ৫. কোনো বাটনের কাজ বদলাতে
```
js/core/85-actions.js-এ ACTIONS.pdfAdd — এখন ফাইল বেছে নেওয়ার পর সরাসরি রিডারে নিয়ে যাবে।
```

## ৬. রিলিজ / আপডেট
```
index.html-এর ?v= আর sw.js-এর CACHE নাম বাড়িয়ে দিন (sanatana-v109-…),
তারপর build/build.py; ZIP বানিয়ে দিন।
```

> নিয়ম: `js/app.js` কখনো হাতে নয় — শুধু `js/**` ফাইল, শেষে `python3 build/build.py`।
