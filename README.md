## অ্যাপ চালানো
```bash
python3 -m http.server 8001      # তারপর ব্রাউজারে http://localhost:8001
```

## কোডের গঠন (নতুন)
`js/app.js` এখন স্বয়ংক্রিয়ভাবে **৩৭টি ছোট ফাইল** জোড়া লেগে তৈরি হয় —
একটি পেজ বদলাতে শুধু সেই একটি ফাইল খুললেই হয়:

```
js/core/      ভিত্তি — state · actions · bindings · router · search · storage
js/views/     পেজগুলো — home · library · gita · puja · panjika · settings · storage …
js/features/  ইঞ্জিন — পূজা-মঞ্চ · PDF · কুইজ
js/app.js     ⚠️ জোড়া লাগানো ফাইল — হাতে বদলাবেন না
build/build.py  জোড়া লাগানোর স্ক্রিপ্ট (নতুন ফাইল যোগ করলে একবার চালান)
```

কোড বদলের পর:
```bash
python3 build/build.py           # js/app.js আবার তৈরি হবে
```

## ফাইল স্টোরেজ (নতুন ফিচার)
`#/storage` পেজে ব্যবহারকারী নিজের **PDF · ছবি · গান · ভিডিও** যোগ করতে পারেন —
সব ব্রাউজারের IndexedDB-তে (`svp-media`), কোনো সার্ভারে যায় না।
গানের কার্ডে “সংগীত করুন” চাপলে সেটিই অ্যাপের ব্যাকগ্রাউন্ড সংগীত হয়।

## ফাইল কাঠামো
```
app/
├── index.html               # শেল (view + tabbar + toast/fx)
├── manifest.webmanifest     # PWA মেটাডেটা
├── css/
│   └── app.css              # ডিজাইন টোকেন + সব কম্পোনেন্ট/স্ক্রিন
└── js/
    ├── gita.js              # শ্রীমদ্ভগবদ্গীতা — ৭০১ শ্লোক (বাংলা লিপি + দেবনাগরী), যাচাই করা
    ├── gita-bn.js           # গীতার বাংলা অনুবাদ ও সহজ ভাষ্য (৭০১ শ্লোক সম্পূর্ণ)
    ├── data.js              # কনটেন্ট ডেটা (গ্রন্থ, শ্লোক, কুইজ, পূজা, পঞ্জিকা, সেবা, প্রোভাইডার)
    └── app.js               # রাউটার + স্টেট + স্ক্রিন + ইন্টারঅ্যাকশন
```
কোনো বিল্ড স্টেপ নেই, কোনো বাইরের লাইব্রেরি নেই — শুধু `python3 -m http.server` বা যেকোনো স্ট্যাটিক হোস্টে চলে।

## ডিজাইন
- **ডার্ক মোড (ডিফল্ট):** মেরুন-গোল্ড, প্রদীপের শিখা, ভাসমান বোকেহ, ফিল্ম গ্রেইন।
- **লাইট মোড:** আপনার দেওয়া ছবির **ক্রিম + সিঁদুর লাল পাটা-বর্ডার**।
- টাইপ স্কেল, ৮pt স্পেসিং, স্টেট (hover/active/disabled/focus-visible), `prefers-reduced-motion` সম্মান।

## ডেটা কোথায় থাকে
`localStorage`-এ (`svp_*` কী)। স্যান্ডবক্স/প্রাইভেট মোডে না পেলে মেমরিতে চলে — অ্যাপ ভাঙে না।
রিসেট: **আমি → ডেমো ডেটা রিসেট**।

## বাস্তব প্ল্যাটফর্মে যাওয়ার পরের ধাপ
1. **ব্যাকএন্ড:** Supabase (Postgres + Auth OTP + Storage) — `00-MASTER-GUIDE.md`-এর স্কিমা অনুযায়ী।
2. **পেমেন্ট:** bKash/Nagad + SSLCommerz, এসক্রো ও দ্বিমুখী লেজার।
3. **কনটেন্ট:** শাস্ত্রীয় পর্যালোচনা বোর্ড → API থেকে বই/শ্লোক সিঙ্ক।
4. **রিয়েল পঞ্জিকা API** (এখন গণনা-ভিত্তিক নমুনা ডেটা)। বাংলা তারিখ বাংলাদেশের **২০১৯ সংশোধিত পঞ্জিকা** (বৈশাখ–আশ্বিন ৩১ দিন, ফাল্গুন ২৯/৩০, ১ বৈশাখ = ১৪ এপ্রিল) অনুসারে গাণিতিকভাবে হিসাব হয়; তিথি/নক্ষত্র/শুভসময় এখন নমুনা — প্রকাশের আগে সত্যিকারের পঞ্জিকা সূত্র দিয়ে প্রতিস্থাপন করা দরকার।
5. **PWA অফলাইন ক্যাশ** (service worker) + Play Store (Capacitor)।

> ডেমো পঞ্জিকা ও কিছু কনটেন্ট নমুনা — প্রকাশের আগে শাস্ত্রীয় পর্যালোচনা বাধ্যতামূলক।
